## B18 — Glossary command admission

- `cast-glossary-input-regular-descriptor`: open nonblocking, inspect the opened
  regular-file descriptor and close it on every outcome. Regular-file symlinks
  remain supported; the existing 8 MiB/10,000-entry budgets still apply.
- `cast-glossary-duplicate-json-member-refusal`: reject duplicate object members
  at every nesting depth, including escaped spellings, before glossary writes.
  Separate duplicate-term entries retain their skipped-entry semantics.
- `cast-maintenance-selector-integer-domain`: canonical positive ASCII IDs within
  the backend PK range; reject malformed IDs before queries and unknown explicit
  transcript selections before any processing. Nonnumeric slugs remain supported.

Initial regression run: **28 failed, 1 passed** against unchanged `develop`.
A further strict-backend-range regression failed for Podcast's inherited
relational PK (SQLite hides this distinction by returning int64 for every type).
The selector now follows the public target-field chain before requesting the
backend range; boundary values and refusal are covered for both PK types.
Existing bounded-read tests now exercise the descriptor-based reader, including
an exact limit, simulated growth, closure, valid import and dry-run paths.

## B19 — Rendition identity and repair

- `cast-rendition-direct-generation-database-affinity`: carry source aliases
  through gallery/post inventory and creation; group post images by alias and
  use public Wagtail single-rendition creation with a bound related manager.
  Shared cache keys without database identity are bypassed. Tests use colliding
  image PKs/hashes, warmed default cache entries and actual filesystem output.
- `cast-rendition-existing-row-missing-file-repair`: include lost physical files
  in the required rendition plan; deduplicate inventory existence checks by
  storage/key. Repair existing rows using Wagtail's public file generation and
  cache APIs, verify saved files, and preserve usable policy counterparts until
  all replacements succeed. Failure/rollback and retry are covered.

Initial regression run: **5 failed** against unchanged `develop`. A further
commit-callback regression failed against an intermediate row-deletion repair:
Wagtail's delayed cleanup deleted the replacement at its reused filename.
Preserving the row avoids scheduling that deletion; the regression now passes
with real commit callbacks. Failed DB publication cleans the attempt's new file.

## B20 — Poster publication and probe boundary

- `cast-poster-recalc-current-video-publication`: conditional poster-only update
  compares original/poster storage names and extraction timestamp. Preserve
  concurrent titles; reject source/poster/timestamp conflicts and compensate
  only unreferenced attempt-owned output. Tests include deterministic barriers
  between separate connections and actual temp storage. Storage names identify
  generations; in-place source overwrites remain outside that contract.
- `cast-video-probe-url-diagnostic-privacy`: fixed ID/phase/failure diagnostics;
  no URL, argv or raw exception text in logs/command errors. Capture ffmpeg
  stdout/stderr; synthetic signed/userinfo/fragment sentinels stay private.
- `cast-video-poster-output-pixel-admission`: refuse output exceeding 8192 pixels
  on either side or 16,777,216 pixels total before extraction. Bound aspect
  metadata to 64 characters and refuse exponential notation before rational
  arithmetic. Keep normal anamorphic/rotated geometry and exact boundary output.

Confirmed baseline regression run: **11 failed** against an isolated archive of
unchanged `develop` with the same installed dependencies. The archive and logs
are outside the checkout. No production data or remote media services are used.
