# Python 3.14 Support

**Date:** 2025-10-12
**Status:** Planned

## Goal

Add Python 3.14 support to django-cast and clean up outdated Python version references.

## Current State

- Minimum Python version: 3.11 (3.10 was dropped in version 0.2.39)
- Currently tested in tox: Python 3.11, 3.12, 3.13
- Tests are already running with Python 3.14
- Several configuration files have outdated references to Python 3.9 and 3.10

## Notes

- Python 3.10 was already dropped in version 0.2.39 (2024-10-13)
- Python 3.9 was dropped in version 0.2.23
- The `requires-python = ">=3.9"` in pyproject.toml is outdated and inconsistent with actual support
- All dependencies should be verified to support Python 3.14

## Django Compatibility

- **Python 3.14 + Django 4.2:** Not supported. Django 4.2 officially supports Python 3.8-3.12 only
- **Python 3.14 + Django 5.2:** Supported. Django 5.2 is the first version with Python 3.14 compatibility
- Tests fail with Django 4.2 + Python 3.14 due to incompatibilities in Django's test framework (`ContextList.dicts` attribute errors)
- Django ticket #35844 tracks Python 3.14 compatibility work
