## Changes

- B15: propagate the owning database through numeric media lookup and gallery
  creation; use the locked current persisted Post body for synchronization.
  Read serialized StreamField chooser IDs without default-database resolution.
  Draft previews and the caller's in-memory body remain request-local.
- B16: reject nonfinite, negative and unrepresentable elapsed chapter offsets;
  preserve microseconds, log/skip invalid extracted sets without replacing marks.
  Text input admits 1000 chapters / 262144 characters before constructing forms;
  duplicate membership uses a set while preserving input order and first errors.
- B28: allow Wagtail Page models and explicitly listed public non-page models
  (`CAST_COMMENTS_ALLOWED_TARGET_MODELS`) before querying selected rows. Reload,
  lock and admit the current target after moderation on stock and Ajax posts.
  Ownership stays transactional and optional observers run after commit.
  Separate restriction/ancestor-table updates are not serialized by target row
  locks; see the documented residual restriction-tree race.

## PostgreSQL and browser acceptance

The implementation sandbox could not start PostgreSQL (`shmget`) or Chromium
(`bootstrap_check_in`). The integration ran these gates outside it, with a
disposable local PostgreSQL 17 (`CAST_TEST_DB_PORT` set to its port):

```sh
just check-postgres
CAST_TEST_DB_ENGINE=django.db.backends.postgresql CAST_TEST_DB=cast_r101_tests \
  CAST_TEST_DB_USER=postgres CAST_TEST_DB_PASSWORD=postgres CAST_TEST_DB_HOST=127.0.0.1 \
  .tox/postgres/bin/python -m pytest -n 0 -p tests.postgres_check --create-db -q \
  tests/media_handling/media_relation_atomicity_test.py tests/comments/comment_database_races_test.py \
  tests/comments/comment_target_admission_test.py tests/media_handling/post_media_authority_test.py \
  tests/chapter_admission_test.py tests/comments/comment_page_access_test.py tests/forms_test.py
CAST_RUN_BROWSER=1 uv run pytest -n 0 tests/comments/comment_browser_test.py tests/transcript_admin_browser_test.py
```

The first PostgreSQL run found two test-only defects in
`media_relation_atomicity_test.py` (a fake post without database state and a
post factory call without title/slug); both were fixed before integration.

No owner decision is needed. Public non-page consumers must choose their own
explicit allowlist on upgrade. Read-only inspection of homepage/python-podcast
comment settings found existing Cast-page integrations, with no required
consumer change. No sibling repository was modified.
