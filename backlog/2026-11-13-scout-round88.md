# Scout round 88: credential, transcript and contributor admission

Implemented against `develop` at `0b1c58cb8352b841a57b1ce75c1a99a783f204a4`.
All four scout scopes remained applicable on the fresh SSH checkout.

## B21

- `cast-voxhelm-blank-token-save-current-value`: blank settings forms preserve
  the token current at the database write, including deferred Wagtail saves.
  Explicit replacement/removal compares the form instance's original token
  under that same write lock and refuses a conflicting save.
- `cast-cli-transcript-completion-attempt-authority`: synchronous generation
  claims the existing per-audio attempt authority before remote submission.
  Completion checks that authority and the initial artifact revision before
  staging files; failures and success update only the owned attempt.

## B22

- `cast-contributor-link-assignment-write-race`: link owner changes and episode
  assignment saves serialize on the same link row and write alias. Assignment
  saves reload cached link relations before validation. The existing save-argument
  normalizer keeps lock and save database selection together.
- `cast-voice-reference-source-range-domain`: finite nonnegative bounds must be
  increasing, fit the DecimalField domain and stay within known audio duration
  (an exact end is valid). Unknown duration remains supported. Outbound request
  construction skips unusable legacy rows before URL resolution/submission.

The contributor and voice-reference specifications and user documentation are
updated. Neither consumer site needs a configuration or schema change; their
existing `develop` dependency references remain valid.

## Follow-up hardening after review

- The settings form round-trips an opaque fingerprint of the token stored when
  the page was rendered (never the token itself). Replacing or removing the token
  from a page opened before another administrator's change is refused with a
  form error; the model save repeats the check under the row lock.
- The synchronous `generate_transcripts` command no longer preempts an
  admin-queued or running generation: it reports that audio as skipped. An
  interrupted command wait marks its own attempt failed instead of leaving it
  running.

## Validation

Each scope has focused regressions that failed on the unchanged source. The
contributor ownership races (both writer orders, create and update) run in the
`postgres` and `postgres-wagtail81` tox environments against a local
PostgreSQL; they skip on SQLite. Merge gates: `just check` (100% coverage), the
JavaScript checks, the Sphinx build with warnings as errors, the tox matrix and
both PostgreSQL environments.
