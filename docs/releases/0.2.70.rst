0.2.70 (unreleased)
-------------------

Upgrade actions
~~~~~~~~~~~~~~~

- Programmatic Voxhelm settings form submissions that replace or remove a token
  on an existing row must include the form's rendered ``api_token_version`` value.

- Editor API Markdown fields now reject fenced or indented code nested in a list
  or block quote with ``400 validation_error`` code ``nested_code`` and its
  source lines. Such code used to pass through rich-text conversion inside the
  paragraph block, which could collapse its whitespace. Clients sending nested
  code must move it out of the list or quote into a standalone code block.
- The editor contributor list now returns ``400 validation_error`` at ``slug``
  for more than 100 distinct ``slug`` filters (``too_many``) or a slug longer
  than 50 characters (``max_length``).

- Editor media lists accept up to 20 distinct ``tag`` filters. Repeating a tag
  uses the same predicate. Larger distinct sets return ``400 validation_error``
  at ``tag`` with code ``too_many``.

- Editor audio PATCH now follows the editor page write rules for database
  routing: the audio row, collections, tags, tagged items and content types must
  be read and written on one database. Primary/replica routers that send reads
  of ``Audio``, Wagtail's ``Collection``, taggit's ``Tag`` or ``ContentType`` to
  a replica now get ``400 validation_error`` at ``database`` with code
  ``unsupported``. Route those reads to the primary to keep using audio PATCH.

Features
~~~~~~~~

Security and hardening
~~~~~~~~~~~~~~~~~~~~~~

- Use the admitted comment for flag confirmation and check its visibility under
  the comment row lock before recording a flag.

- Return 404 on slug-based feed and episode routes when Wagtail cannot resolve
  a site root for the request. Wagtail's configured default site still applies.

- Mark restricted Twitter Player responses private and uncacheable.
- Load the Twitter Player bootstrap as a static script so the card page needs no
  inline script. The Podlove embed still loads resources from ``cdn.podlove.org``.
- Bound the number and length of editor contributor slug filters before querying
  the database.
- Trim editor contributor search terms and reject terms longer than 128
  characters with ``400 validation_error`` at ``q`` before querying contributors.
- Limit the chapters JSON endpoint to GET and HEAD before looking up audio.

  library, so the rest of the list remains available.

  rendition. Report changed pairs and retain the old files. Retire an obsolete

  ``generate_transcripts``, including transcripts finished during an earlier job.

  changes cannot mix base pages with specific page and media data.
