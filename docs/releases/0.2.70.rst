0.2.70 (unreleased)
-------------------

Upgrade actions
~~~~~~~~~~~~~~~

- Editor API Markdown fields now reject fenced or indented code nested in a list
  or block quote with ``400 validation_error`` code ``nested_code`` and its
  source lines. Such code used to pass through rich-text conversion inside the
  paragraph block, which could collapse its whitespace. Clients sending nested
  code must move it out of the list or quote into a standalone code block.
- The editor contributor list now returns ``400 validation_error`` at ``slug``
  for more than 100 distinct ``slug`` filters (``too_many``) or a slug longer
  than 50 characters (``max_length``).

Features
~~~~~~~~

Security and hardening
~~~~~~~~~~~~~~~~~~~~~~

- Return 404 on slug-based feed and episode routes when Wagtail cannot resolve
  a site root for the request. Wagtail's configured default site still applies.

- Mark restricted Twitter Player responses private and uncacheable.
- Load the Twitter Player bootstrap as a static script so the card page needs no
  inline script. The Podlove embed still loads resources from ``cdn.podlove.org``.
- Bound the number and length of editor contributor slug filters before querying
  the database.

Fixes
~~~~~

- Use an available audio variant in Twitter Player embeds and display an
  unavailable message when no source can be played.

- Return 404 for ambiguous live episode slugs in Twitter Player and transcript URLs.

- Resolve feed and episode URLs when the blog or podcast is the Wagtail site root.

- Bound original reads in the GPS inventory before opening images for inspection.
- Verify final media sync bytes before retiring the recovery stage.
- Skip glossary import entries containing lone surrogates or NUL without rolling back valid entries.
- Refresh transcripts in bounded batches when running ``apply_transcript_glossary --all``.

- Run every quickstart child with the generated settings and project import path.
- Refuse automatic episode numbering when the next counter would exceed the portable field limit, with a field error in the Wagtail page editor and the editor API.
- Invalidate stale absolute rich-text page links when refreshing their relative URLs.
- Treat zero and negative stored audio durations as unknown in the custom player.
- Use manual transcript overrides directly, including empty stored overrides.
- Let editors repair missing or invalid glossary episode references while keeping saved decisions.
- Retire glossary occurrence decisions for missing raw segments during refresh.
- Preserve saved corrections and public transcript files when correction segment starts are invalid or duplicated.
- Preflight database routing for all explicitly selected transcripts before applying the glossary.
- Continue applying the glossary after an individual refresh fails, using a bounded failure diagnostic.
- Synchronize speaker mappings on the database where the transcript was saved.
- Fetch only uncached gallery image IDs, preserving the order and captions of surviving entries.
- Resolve the original storage URL once for all image slots that fall back to it.
- Build inline transcript rows when the panel first opens.
- Show loading status in transcript panels opened during an existing request.
- Update only the previous and next active transcript marks during navigation.
- Reuse folded transcript cue text and leave unmarked rows intact during search edits.

- Reload the parent and its concrete type on the locked database before checking editor slugs.
- Build editor publish responses from the concrete page reloaded on the write database.
- Match post transition handoffs to the exact destination URL and navigation entry where available.
- Clear shared post transition names without an unhandled rejection when a transition is skipped.

- Seed a new transcript correction sidecar from the Podlove read used to validate segment timing.
- Fill missing player cue ends in one pass after sorting, including equal-start groups.
- Skip malformed chapter entries in the player payload and chapters endpoint.
- Resolve the selected blog in one query before syncing renditions.
- Canonicalize SVG rendition specifications before detecting misses in post previews.
- Fall back to the configured theme when a visitor's session theme has been retired.
- Require template files during theme discovery and warn about directories at soft-required template paths.
- Reject revisions belonging to another object before assigning an episode number.
- Keep episode and revision objects retryable when saving episode numbering fails.
- Keep modal facet snapshots and taxonomy counts on the resolved blog's database.
- Reuse prefetched image and gallery renditions in warm post previews.
- Resolve database search membership once per modal facet request.
- Reuse the modal result count for facet groups without a selection.
- Copy nested Podlove font overrides for each player configuration.
- Report malformed nested Podlove theme settings in Django system checks
  and keep the player configuration endpoint usable with safe fallbacks.

- Verify staged and published bytes before reporting a successful
  ``media_replace``, and retain the verified staging key if final verification fails.
- Use reserved sync staging keys for ``media_replace`` and skip leftover keys
  in both the current and legacy formats in media backup and restore.

- Reject quickstart project names whose spelling changes under Python's NFKC
  identifier normalization before creating files.
- Read quickstart templates and write generated Python and HTML files as UTF-8,
  including for Unicode project names under an ASCII text locale.
- Escape console output the terminal encoding cannot represent in quickstart
  and its non-interactive ``manage.py`` steps, so a Unicode project name no
  longer crashes setup on an ASCII console.
- Reject empty or invalid FFmpeg poster frames before writing to media storage.
- Terminate FFmpeg and FFprobe when captured output exceeds the stdout or stderr
  limit, keeping diagnostics separate from metadata.
- Retire unreferenced poster files when publication is interrupted, preserving
  the original interruption if cleanup fails.
- Stream the video poster backfill in batches in primary-key order.
- Probe audio duration and chapters from HTTP(S) storage URLs without requiring
  the storage backend to provide a local path.
